# Introduction to Computer Programming in Java

A collection of Java practice codes, weekly exercises, and object-oriented programming (OOP) examples covering fundamentals through advanced concepts.

## Topics Covered

### 1. Imperative Foundations
- **Variables and Operators:** Data types, arithmetic operators, bitwise logic, and type casting.
- **Control Flow:** `if`, `else-if`, `switch-case` statements, and conditionals.
- **Loops & Iteration:** `for`, `while`, `do-while`, nested loops, and pattern printing.
- **Arrays:** 1D and 2D arrays, searching, and traversal.

### 2. Object-Oriented Programming (OOP)
- **Classes & Objects:** Constructors, instance variables, methods, and `this` keyword.
- **Encapsulation:** Access modifiers (`private`, `public`, `protected`), getters and setters.
- **Collections:** `ArrayList`, dynamic lists, and object aggregation.
- **Inheritance & Polymorphism:** Method overloading, method overriding, `super` keyword, dynamic binding, and type casting.
- **Abstract Classes & Interfaces:** Interface implementation, abstract methods, and polymorphism.

## How to Run

1. Navigate to any exercise folder.
2. Compile the Java file:
   ```bash
   javac Example.java
   ```
3. Run the compiled program:
   ```bash
   java Example
   ```
